# ДЗ №25 — Программы с интерфейсом (GUI)

**Курс:** Разработка Web-приложений на Python (Django) — Компьютерная академия «Шаг»
**Студент:** Утесеитов Али

## Задание
1. а) Набросок дизайна программы, которая делает запрос на jsonplaceholder с определённым id.
2. б) Реализация программы на tkinter.
3. в) Сохранение полученного объекта в папку.

## Что делает программа
- Выбор ресурса: `posts`, `comments`, `albums`, `photos`, `todos`, `users`
- Ввод id (с проверкой: только целое число в допустимом диапазоне)
- GET-запрос к `https://jsonplaceholder.typicode.com/<ресурс>/<id>`
- Вывод ответа в окне в формате JSON
- Кнопка **«Сохранить в папку»** — сохраняет объект в `saved/<ресурс>_<id>.json`
- Обработка ошибок сети (окно с ошибкой, статус красным)

## Запуск
```bash
pip install -r requirements.txt
python main.py
```

## Структура
```
├── main.py              # программа (tkinter)
├── requirements.txt     # зависимости (requests)
├── saved/               # сюда сохраняются полученные объекты
│   └── posts_1.json
└── screenshots/
    ├── design.png       # набросок дизайна
    └── app.png          # скрин работающей программы
```
